# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

If you discover a security issue or credential exposure, please report it privately:

1. Do not open a public issue.
2. Email details to `security@relay-ops.internal` or contact the repository maintainer directly.
3. Include reproduction steps, affected files, and potential impact.

We will review the report within 48 hours and coordinate a fix.
